# Catastrophe Modeling & Climate Risk Data Analytics Portfolio

This repository contains reproducible data pipelines and analytics engines simulating how insurance, reinsurance, and municipal planning teams quantify natural hazard exposure and climate risk.

## 🛠️ Portfolio Project Stack

### 1. Wildfire Risk Tiering & Exposure Analysis (Python & Tableau)
* **Objective:** Map and quantify financial property concentrations against wildfire risk boundaries.
* **Tech Stack:** Python (GeoPandas), SQL, Tableau Public.
* **Key Metric:** Calculated Total Insured Value (TIV) exposure profiles across High and Very High threat tiers to inform underwriting constraints.

### 2. Probabilistic Tropical Cyclone Loss Modeling (Python)
* **Objective:** Build a mini-catastrophe modeling engine to calculate Exceedance Probability (EP) Curves.
* **Tech Stack:** Python (Pandas, NumPy, Matplotlib).
* **Key Metric:** Modeled wind decay and vulnerability damage functions across 1,000 stochastic years to isolate the 100-year and 250-year return period loss benchmarks.

### 3. Coastal Flood Hazard Projection & Infrastructure Resiliency (GIS & OpenStreetMap API)
* **Objective:** Evaluate critical care infrastructure vulnerability under 2050 climate change pathways.
* **Tech Stack:** OpenStreetMap (Overpass Turbo API), GeoPandas (CRS Projections & Centroids).
* **Key Metric:** Modeled asset migration thresholds across IPCC SSP2-4.5 and SSP5-8.5 carbon pathways to locate critical asset failure points.
